# Imported historical observations

This directory holds the initial, privacy-scrubbed WSL/ROCm evidence ledger
transferred into this lab on 2026-10-19. The records originated from a private
local language-model training workload, but contain no model data, weights,
prompts, private source code, account identifiers, full paths, or raw log
bundles.

They are historical observations, not completed reproductions. Each candidate
must be re-created with the synthetic test protocol in this repository before
it becomes an upstream issue or a claim about vendor ownership.

The environment snapshot, test matrix, upstream-outreach checklist, focused
WSL/ROCm triage plan, and numbered evidence notes are retained together so the
control results and mitigations do not lose context.
