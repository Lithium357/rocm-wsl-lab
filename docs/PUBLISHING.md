# Publishing findings

Validated findings and reviewed evidence are recorded in this repository and linked from outputs/FINDINGS.md. Reuse an existing tracking issue when the finding or upstream signature is already known; otherwise add a clearly scoped issue with control, reproduction, observed/expected behavior, source or installed-version fingerprint, limitations, and tested mitigation.

Follow docs/DATA_POLICY.md before every upload. Raw work directories, private identifiers, models, data, production source, and unreviewed logs remain outside Git. A CPU-only source reduction must never be described as installed GPU reproduction. Archive merged fixes and withdrawn candidate patches clearly.

Publication authorization covers this lab repository. Posting to third-party upstream repositories, opening upstream PRs, or messaging maintainers remains a separate action requiring explicit authorization.
